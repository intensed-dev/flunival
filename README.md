# Flunival

Custom GitHub profile badges.

Open:

`https://intensed-dev.github.io/flunival/#username`

Flunival reads the username from the URL hash and loads public profile data from the GitHub API.

## Badges

- Followers
- Public repositories
- Repository stars
- GitHub join year
- More profile badges can be added in `script.js`

Icons are provided by [Lucide](https://lucide.dev/).
